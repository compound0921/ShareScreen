# 发布说明

## 1.2

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

### 新增

- **发布件改成文件夹。** 解压出来是 `ShareScreen.exe` 加上一个 `tools/` 目录,
  ffmpeg 和 MediaMTX 都看得见、也换得掉;以前它们被压进 exe 里,编出来是一个
  165 MB 的单文件,换版本只能重新编译。

### 修复

- 资源管理器里 exe 显示的是 Windows 默认图标,不是程序自己的图标。
- 关掉控制页之后程序仍在后台跑,ffmpeg 和 MediaMTX 都不退;现在关掉页面会一起
  退出(等 3 秒;刷新页面、切到别的标签页都不会误判)。

### 说明

- 别只把 `ShareScreen.exe` 单独拷走,要和 `tools/` 放在一起 —— 找不到会启动失败,
  报错里写明缺哪个文件、该放到哪。
