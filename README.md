# ShareScreen

Windows 屏幕共享工具 —— 服务端采集本机画面,客户端用浏览器直接观看,无需安装任何软件。

- **平台:** Windows 10 1809+
- **网络:** 公网访问(家宽公网 IP + 端口映射直连,无 VPS)
- **观众数:** 常规 1 人(由 4.57 Mbps 上行决定,见架构设计 §7.6.5)
- **采集源:** 屏幕 / 单个窗口 / OBS

## 技术方案

```
ffmpeg(采集+硬编) ──RTMP/SRT──▶ MediaMTX ──WHEP/WebRTC──▶ 路由器端口映射 ──▶ 浏览器
                                     ▲                                        (8443/tcp + 8189/udp)
OBS ────────────WHIP 直推────────────┘
```

采集和编码交给 ffmpeg,WebRTC 服务端交给 MediaMTX,自定义网络代码量为零。
程序本身是一个 Go 单二进制,内嵌上述两个 exe,提供 localhost 网页作为扁平化控制界面。

**关键约束:上行带宽。** 每个观众占用一路独立码率,家宽上行是硬上限。
默认档位因此定为 **1280×800 @ 60fps @ 3 Mbps**,但**分辨率 / 帧率 / 码率 / 编码器均可自行选择**,
界面会实时显示当前设置能支撑几个观众 —— 详见 [架构设计 §6.5](docs/架构设计.md#65-可调参数) 和 [§7.6.5](docs/架构设计.md#765-上行带宽规划)。

> 注 1:码率固定时帧率翻倍意味着每帧比特数减半。60fps 下画质不满意时,**优先降分辨率而不是降帧率**。
> 注 2:ffmpeg 不支持运行时改这些参数,调整时会重启采集进程,观众侧中断约 1–2 秒。

## 目录结构

```
ShareScreen/
├── docs/                  文档
├── tools/                 第三方组件(需自行下载,见 Stage0 手册)
│   ├── mediamtx/          mediamtx.exe + mediamtx.yml
│   └── ffmpeg/bin/        ffmpeg.exe
└── README.md
```

> `tools/` 下的两个组件是免安装的单文件程序,不纳入版本管理。
> Stage 1 会把它们内嵌进最终的可执行文件,用户届时无需单独安装。
