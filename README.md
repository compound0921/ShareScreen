# ShareScreen

Windows 屏幕共享。本机采集画面,别人用浏览器打开链接就能看,不用装客户端。

发布件是一个文件夹:程序本体、`tools/` 里的组件和一份 `使用说明.txt`。
解压后保持原样即可运行。

## 运行

双击 `ShareScreen.exe`。浏览器会打开控制页,托盘出现图标。

| 托盘操作 | 效果 |
|---|---|
| 双击图标 | 打开控制页 |
| 右键 → 开始 / 停止共享 | 不切浏览器 |
| 右键 → 退出 | 停止并退出 |

**关控制页 = 关程序。** 页面和程序之间有一条长连接,关闭页面 3 秒后程序退出。
刷新不算关闭;切到别的标签页、锁屏、合盖都不影响。用 `-no-browser` 启动时,
程序会一直在托盘里待着。

日志:`%LOCALAPPDATA%\ShareScreen\sharescreen.log`。

### 端口被占用

启动时端口被占用不会直接闪退:

- 已有 ShareScreen 在跑:打开它的控制页后退出;
- 自家残留的 `mediamtx` / `ffmpeg`:自动结束再继续;
- 别的程序占用本地端口:询问是否换端口;
- WebRTC 播放端口或媒体端口被占:不自动换,说明原因后退出。

改过端口后要同步改路由器映射。

## 使用

### 采集源

| 选项 | 说明 |
|---|---|
| **屏幕(WGC 采集,推荐)** | 默认。走 DWM 合成层,GPU 采集打不开的机器也能用;只采主显示器。需要 Windows 10 1903+ |
| 屏幕(GPU 采集) | DXGI 桌面复制,CPU 占用最低。个别显卡/驱动上可能抓不到画面 |
| 屏幕(兼容模式) | 任何 Windows 上都能用,CPU 占用更高 |
| 单个窗口 | 窗口被遮挡时,画面会被遮挡物盖住 |
| OBS 虚拟摄像头 | 只有画面;声音来自桌面音频 |
| OBS 直推 | 画面和声音都由 OBS 提供 |

### 声音

默认开启。程序抓播放设备的回环,换耳机、插 HDMI、切蓝牙会自动跟随。

听不到声音时,先检查「采集哪台设备的声音」:系统默认设备不一定是有声音的那台。
程序发现采到的设备一直静音、而别处在放声音时会弹提示,可以直接切换。指定设备
被拔掉会自动退回默认设备。

采不到声音时退化成无声画面,不会导致共享起不来。

观看链接末尾的 `?muted=0` 不能丢,否则播放页默认静音。链接由程序生成,已带好。

#### OBS 直推

1. 采集源选「OBS 直推」,复制页面上的推流地址;
2. OBS → 设置 → 直播:服务选 **WHIP**,地址填 `http://127.0.0.1:8889/live/whip`;
3. 确认 OBS 混音器里有「桌面音频」;
4. 点 OBS「开始推流」。

必须用 WHIP,不能用 RTMP(RTMP 只能带 AAC,浏览器 WebRTC 不认)。需要 OBS 29+。

### 参数

默认 `原始分辨率 / 60fps / 3 Mbps + 96kbps 音频`。界面会估算能支撑几个观众:
`上行带宽 × 0.7 ÷ (视频码率 + 音频码率)`。上行带宽请填实测值;画质不够时优先
降分辨率,别降帧率。改参数会重启采集,观众侧黑屏约 1–2 秒。

## 观众怎么看

打开链接即可。**链接本身就是凭据**,不要发到公开场合。

## 远程控制

让对方经你同意后操作这台电脑(鼠标、键盘、剪贴板文本)。

### 对方请求

默认「接受请求开启共享与远控」是开的:拿着链接的人可以请求你开共享和远控。
你会在屏幕右下角看到弹窗,点「允许」后才开始。不点则一分钟作废。

不想保留这个入口,取消勾选「接受请求开启共享与远控」,程序就不再监听远控端口。

### 已经开着之后

勾选「允许远程控制」后,把「可控制链接」发给对方。对方点「申请控制」,你批准后
才能操作。

**控制密码**是一条捷径:对方填对密码即可直接拿到控制权,不用每次等你批准。
新装默认密码 `123456`;清空密码即关闭这条捷径,回到每次批准。密码以明文存储和
传输,只当临时暗号用。改密码只影响下一次申请,不会打断正在控制的人。

批准有两条路:右下角通知上的「允许 / 拒绝」,或控制页右栏的批准框。通知里的
回车不会做出选择,`Esc` 是拒绝。

### 边界

- 只有整屏采集能远控;窗口采集和 OBS 不行。
- 远控期间画面里不显示主机光标,切换会重启采集(黑屏几秒)。
- 你在用键鼠时对方操作会自动让开,停手 1 秒后恢复。
- 锁屏界面、UAC 弹窗、Ctrl+Alt+Del、管理员窗口无法控制。
- 剪贴板同步是单独开关,默认关闭。
- 远控默认关闭;「接受请求开启共享与远控」默认开启,是唯一默认绑 `0.0.0.0`
  的功能,不需要就取消勾选。
- 传输是明文的,不要在不可信网络里开启。

## 公网访问

### 自动(UPnP)

控制页勾选「自动配置路由器端口映射(UPnP)」。程序会建好端口映射并填入公网地址,
公网 IP 变化后自动跟上。

- 公网端口内外一致:WHEP `8889/tcp`、ICE `8189/udp`;
- 仍要放行 Windows 防火墙的 `8889/tcp` 和 `8189/udp`;开远控时再加 `8090/tcp`;
- 路由器关闭 UPnP、运营商级 NAT、双重 NAT 时自动映射不可用,改走手动路线或
  VPS 中转。

排查:

```bash
go run ./cmd/portmapcheck          # 只读
go run ./cmd/portmapcheck -map     # 试建一次映射,试完删除
```

### 手动

路由器加映射:

| 名称 | 协议 | 外部端口 | 内部端口 |
|---|---|---|---|
| ShareScreen-WHEP | TCP | 8443 | 8889 |
| ShareScreen-ICE | **UDP** | 8189 | 8189 |
| ShareScreen-RemoteControl | TCP | 8090 | 8090 |

- UDP `8189` 内外端口必须一致;
- **不要映射 1935**,否则任何人都能覆盖你的画面;
- 远控不开时不要加最后一条;
- 同时放行 Windows 防火墙对应端口。

然后在控制页「公网地址」里选路由器报告的地址;用 DDNS 时填 `域名:8443`。
「局域网观看地址」只影响链接显示,不改变映射指向。

最后用手机 4G(关 WiFi)验证公网链路。

## 停止

托盘右键 → 退出,或关闭控制页。ffmpeg、MediaMTX 和 WGC 采集进程会一起退出。

例外:远程控制开着时,关控制页不会退程序,请走托盘退出。

## 构建

需要 Go 1.27+ 和 Rust 工具链(`cargo`)。

准备组件:

| 组件 | 来源 | 放成 |
|---|---|---|
| ffmpeg | [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) `ffmpeg-release-essentials.zip` | `tools/ffmpeg/bin/ffmpeg.exe` |
| MediaMTX | [GitHub Releases](https://github.com/bluenviron/mediamtx/releases) | `tools/mediamtx/mediamtx.exe` |
| wgc-capture | 本项目 `wgc-capture/` | `tools/wgc-capture.exe` |

```bash
cargo build --release --manifest-path wgc-capture/Cargo.toml
cp wgc-capture/target/release/wgc-capture.exe tools/wgc-capture.exe
go build -ldflags "-H=windowsgui -s -w" -o sharescreen.exe .
```

`-H=windowsgui` 去掉控制台窗口;`-s -w` 去符号表。

### 发布

```bash
go run ./cmd/genrelease -version 0.1
```

产出 `dist/ShareScreen-0.1.zip`(约 70 MB),包含:

```
ShareScreen.exe
使用说明.txt
tools/ffmpeg/bin/ffmpeg.exe
tools/mediamtx/mediamtx.exe
tools/wgc-capture.exe
```

把整个 zip 发给对方,解压后双击 `ShareScreen.exe`。发布包自带全部组件,
目标机器不需要装 Go 或 Rust。

`docs/使用说明.txt` 是包内说明的来源;打包时会转成 UTF-8 BOM + CRLF。
