# 发布说明

## 1.3

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

### 新增

- **远程控制。** 观看的人可以申请操作你这台电脑,你点「允许」之后他才能动手 ——
  鼠标、键盘,以及可选的剪贴板文本同步。默认关闭,不开的时候程序**不会多监听
  任何端口**,路由器上也不会多开映射。链接另发一条「可控制链接」,原来的观看
  链接一个字没变,还是只能看。
- 只有整屏采集支持远程控制。窗口会移动、OBS 送进来的是它自己合成的画面,两者
  都没有稳定的屏幕坐标,观众点了也对不上位置。

### 修复

- **换一台机器就可能用不了。** 编码器列表以前是从 `ffmpeg -encoders` 的输出里
  读的 —— 那只是"这个 ffmpeg 构建编译进去了哪些编码器",和机器上插着什么显卡
  没关系。实测一台没插 N 卡的机器:列表里列着 `h264_amf`,一跑就报
  `DLL amfrt64.dll failed to open`,而「自动」恰好必然先选中它。现在启动时会真的
  各编一帧,打不开的从下拉框里剔掉。
- **双显卡的跨 PCIe 拷贝。** 采集抓的是驱动显示器那块 GPU 的画面,编码却可能
  发生在另一块上,数据要跨 PCIe 来回搬。现在按「显示器挂在哪块 GPU 上」给编码器
  排序,同厂商的排前面。
- **编码器起不来时会自动换一个。** 以前选定哪个就死磕哪个,失败等于整个推流失败;
  现在按候选逐个试,并在界面上说明「你选的 xxx 起不来,已改用 yyy」。配置里存的
  仍然是你选的那个,不会被悄悄改掉。

### 说明

- **远程控制是明文传输的。** 和观看链接一样,不开 TLS 的话,对方在你机器上敲的
  东西(包括密码)都会以明文经过网络。别在不可信的网络里开启。
- 开着远程控制时,**关掉控制页不会退出程序** —— 否则你一关页面,对面的人就断了。
  不开的时候行为不变,关页面即退出。
- 界面去掉了几样用不上的东西:上行带宽输入框和观众数估算(两种模式下都只是估算,
  而且家宽上行本来也撑不住多人)、OBS 直推时的 RTMP 地址(OBS 那边只认 WHIP)、
  以及两个二维码(链接本来就是要复制转发的,二维码只让版面变长)。
- OBS 直推模式下不再显示码率 —— 那个值是 OBS 决定的,在这里改了没有实际效果。

## 1.2

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

### 新增

- **发布件改成文件夹。** 解压出来是 `ShareScreen.exe` 加上一个 `tools/` 目录,
  ffmpeg 和 MediaMTX 都看得见、也换得掉;以前它们被压进 exe 里,编出来是一个
  165 MB 的单文件,换版本只能重新编译。

### 修复

- 资源管理器里 exe 显示的是 Windows 默认图标,不是程序自己的图标。
- 关掉控制页之后程序仍在后台跑,ffmpeg 和 MediaMTX 都不退;现在关掉页面会一起
  退出(等 3 秒;刷新页面、切到别的标签页都不会误判)。

### 说明

- 别只把 `ShareScreen.exe` 单独拷走,要和 `tools/` 放在一起 —— 找不到会启动失败,
  报错里写明缺哪个文件、该放到哪。
