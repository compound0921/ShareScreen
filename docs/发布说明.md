# 发布说明

## 1.4

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

这一版把「地址」和「声音」这两条最容易出错、又最难自己发现的路都补上了。

### 新增

- **采集设备没声音时会主动提示。** 采的那台播放设备一直没声音、而另一台设备正在
  放的时候,屏幕右下角会弹一条提示,可以直接点「切换」换到那台正在出声的设备上
  (画面会黑几秒),或者点「忽略」——忽略之后本次共享期间不再提示。判定要求采集
  设备连续静音 10 秒、另一台持续在放,所以一声系统提示音不会把它勾出来。
- **申请远程控制时,主机右下角弹窗里就能批准。** 以前必须切到控制页才能点「允许」,
  人不在浏览器前面就会漏掉整个申请。现在弹窗里可以直接允许/拒绝,带倒计时,到点
  等同于拒绝。弹窗会抢焦点,但**回车被硬性吃掉**:抢焦点的那一刻你多半正在别处
  打字,那个回车是打给别的窗口的。允许只能用鼠标点(Esc 是拒绝)。
- **局域网地址和公网地址改成下拉选择。** 这两个值程序本来就知道(局域网是扫出来
  的网卡,公网是路由器报告的),以前却要用户自己记住并手抄——实测就抄错过:配置里
  留着上一次的公网 IP,而路由器报告的已经变了,公网链接对所有人都打不开。现在
  下拉里直接列出来,选「自定义…」才出现原来的输入框。

### 变更

- **「公网地址」不再需要填端口。** 这个字段以前兼着"公网叫什么"和"外网端口是几"
  两件事,所以填了 IP 忘了端口,链接就会走 80——而映射开在 8889 上,链接是死的
  而界面上看不出来。现在链接生成时自动带上端口,字段只表示"这台机器在公网上叫
  什么"。需要手写端口仍然可以(外网端口被翻译过的部署),写了就用你写的。
- **远程控制开着时,画面里不再显示主机光标。** 控制方改用自己浏览器的光标。
  以前主机光标被画进视频里,控制者看到的是 0.3–1 秒前的位置——手动了指针没动、
  然后追着跑,这就是"拖拽感"的来源(不是延迟,换传输层不会有任何改善)。代价是
  这段时间**观看链接里也看不到光标**,而切换这个开关会重启采集(黑屏几秒)。

### 修复

- **UPnP 报 402 Invalid Args,端口映射建不上。** 根因是程序拿错了本机地址:它取
  网卡列表里的第一个私有 IPv4,而 Windows 返回的顺序是网卡索引、不是路由优先级
  ——这台机器上排第一的是虚拟网卡,真正连到路由器的是另一个地址。于是程序让路由器
  把端口转发到一个不属于该局域网的主机上,路由器回 402 完全正确。现在按路由表推导。
- **公网地址填错了不会说。** 家宽的 IP 会变,而手动填进去的地址程序不会去改,于是
  它会一直错下去——以前只比较端口,压根不看 IP,所以一声不吭。现在和路由器报告的
  外网地址对比,不一致就明说。域名不参与这个判断(DDNS 域名本来就该和当前 IP 不同)。
  只警告,不改用户的输入。
- **UPnP 成功提示只写了一个端口。** 远控开着时一共开了三条,而那一行是界面上唯一
  说明"自动映射都开了什么"的地方——只说一条,就没法确认远控端口到底开没开。
- **远控的端口没进自动映射。** 观看端口和 WebRTC 端口都映射了,远程控制那个 TCP
  端口没有,局域网外的人连不上控制通道。现在一起映射;程序不再需要的端口也会
  **从路由器上撤回**(以前只加不删,旧规则会一直留在路由器里)。
- **地址下拉改了之后,链接不跟着变。** 观看链接和可控制链接现在都会跟着更新,
  以前要刷新整个页面才行。

### 说明

- 音频那条提示的判定依赖系统的端点音量表(`IAudioMeterInformation`)。个别声卡
  驱动不实现这个接口,那台设备就永远报"没在放"——这种情况下提示会**静默失效**,
  不会报错。它是一条提示,不是保障。
- 那条提示不显示倒计时、也不会自己消失:它背后是一个持续存在的状态,不是一份会
  过期的申请。窗口一直挂着,直到你点它,或者那个状态消失(采集设备又出声了、
  另一台也安静了、或者共享停了)。
- 如果你**故意**把某个程序的声音分到另一台设备上,那条提示会是"对的但没用",
  点忽略即可,之后本次共享不再打扰。

## 1.3.1

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

### 变更

- **默认采集源改成「屏幕(推荐)」。** 原来的默认是 GPU 采集(ddagrab),它更快,
  但依赖 DXGI 桌面复制 —— 一部分机器上(尤其是接着外接显示器的笔记本)根本抓不到
  画面。默认值要保证的是"点开始就有画面",所以换成了兼容性最好的那个。它 CPU
  占用比 GPU 采集高,想要更低占用、更高帧率,到「采集源」里选「屏幕(GPU 采集,
  更快)」换回去。

### 新增

- **「采集哪台设备的声音」。** 勾上「共享桌面音频」之后,音频那一栏会多出一个
  下拉框,可以指定从哪台播放设备采声音。默认仍然是「系统默认设备(自动跟随)」,
  和以前的行为一样。

### 修复

- **接了 HDMI 显示器之后,观众只有画面、没有声音。** 程序原先只抓系统默认播放
  设备的回环,而**默认设备不一定是有声音的那台**:笔记本接上 HDMI 之后,系统默认
  常常指到显示器那一路输出,声音其实还从笔记本自己的扬声器出来 —— 采默认设备只
  采到静音,观众那边自然什么都听不到。现在到「采集哪台设备的声音」里换成真正在
  出声的那台就行。
- 指定的音频设备不在了(蓝牙耳机断连、换了声卡)时,退回系统默认设备继续出声,
  并在控制页上说明一句 —— 以前这种情况会整个共享没有声音。

### 说明

- 每台播放设备的混音格式是各自独立的(实测蓝牙耳机 44100Hz、板载扬声器
  48000Hz),换设备之后 ffmpeg 拿到的采样率会跟着变,这是正常的。
- 这个下拉框只在勾了「共享桌面音频」时才显示。听不到声音先确认那一项勾上了 ——
  没勾的话推出去的流里连音轨都没有。

## 1.3

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

### 新增

- **远程控制。** 观看的人可以申请操作你这台电脑,你点「允许」之后他才能动手 ——
  鼠标、键盘,以及可选的剪贴板文本同步。默认关闭,不开的时候程序**不会多监听
  任何端口**,路由器上也不会多开映射。链接另发一条「可控制链接」,原来的观看
  链接一个字没变,还是只能看。
- 只有整屏采集支持远程控制。窗口会移动、OBS 送进来的是它自己合成的画面,两者
  都没有稳定的屏幕坐标,观众点了也对不上位置。

### 修复

- **换一台机器就可能用不了。** 编码器列表以前是从 `ffmpeg -encoders` 的输出里
  读的 —— 那只是"这个 ffmpeg 构建编译进去了哪些编码器",和机器上插着什么显卡
  没关系。实测一台没插 N 卡的机器:列表里列着 `h264_amf`,一跑就报
  `DLL amfrt64.dll failed to open`,而「自动」恰好必然先选中它。现在启动时会真的
  各编一帧,打不开的从下拉框里剔掉。
- **双显卡的跨 PCIe 拷贝。** 采集抓的是驱动显示器那块 GPU 的画面,编码却可能
  发生在另一块上,数据要跨 PCIe 来回搬。现在按「显示器挂在哪块 GPU 上」给编码器
  排序,同厂商的排前面。
- **编码器起不来时会自动换一个。** 以前选定哪个就死磕哪个,失败等于整个推流失败;
  现在按候选逐个试,并在界面上说明「你选的 xxx 起不来,已改用 yyy」。配置里存的
  仍然是你选的那个,不会被悄悄改掉。

### 说明

- **远程控制是明文传输的。** 和观看链接一样,不开 TLS 的话,对方在你机器上敲的
  东西(包括密码)都会以明文经过网络。别在不可信的网络里开启。
- 开着远程控制时,**关掉控制页不会退出程序** —— 否则你一关页面,对面的人就断了。
  不开的时候行为不变,关页面即退出。
- 界面去掉了几样用不上的东西:上行带宽输入框和观众数估算(两种模式下都只是估算,
  而且家宽上行本来也撑不住多人)、OBS 直推时的 RTMP 地址(OBS 那边只认 WHIP)、
  以及两个二维码(链接本来就是要复制转发的,二维码只让版面变长)。
- OBS 直推模式下不再显示码率 —— 那个值是 OBS 决定的,在这里改了没有实际效果。

## 1.2

ShareScreen 是 Windows 上的屏幕共享工具:采集本机屏幕和桌面声音,别人用浏览器
打开链接就能看,不需要装任何客户端。

### 新增

- **发布件改成文件夹。** 解压出来是 `ShareScreen.exe` 加上一个 `tools/` 目录,
  ffmpeg 和 MediaMTX 都看得见、也换得掉;以前它们被压进 exe 里,编出来是一个
  165 MB 的单文件,换版本只能重新编译。

### 修复

- 资源管理器里 exe 显示的是 Windows 默认图标,不是程序自己的图标。
- 关掉控制页之后程序仍在后台跑,ffmpeg 和 MediaMTX 都不退;现在关掉页面会一起
  退出(等 3 秒;刷新页面、切到别的标签页都不会误判)。

### 说明

- 别只把 `ShareScreen.exe` 单独拷走,要和 `tools/` 放在一起 —— 找不到会启动失败,
  报错里写明缺哪个文件、该放到哪。
